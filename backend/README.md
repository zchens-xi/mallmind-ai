# MallMind AI Backend

MallMind AI 的后端服务，提供商城业务、运营管理、数据分析、智能推荐和 AI 客服能力。

## 主要模块

- `mall-admin`：运营管理与数据分析接口
- `mall-portal`：移动商城业务接口
- `mall-ai`：AI 客服、推荐与数据处理
- `mall-search`：商品搜索
- `mall-mbg`：数据库模型与 Mapper
- `mall-common` / `mall-security`：公共能力与安全组件

启动前请先配置 MySQL、Redis、MongoDB、Neo4j 及所需的 AI 服务环境变量。
