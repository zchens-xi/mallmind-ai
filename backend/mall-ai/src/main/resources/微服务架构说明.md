# FastAPI推荐算法微服务架构说明

## 🎯 架构设计理念

您说得非常正确！对于微服务架构，**SpringBoot管理数据库IO + Python专注算法计算** 是最佳实践：

### 1. 微服务职责分离
- **SpringBoot微服务**: 负责数据持久化、缓存管理、用户认证、业务逻辑
- **Python FastAPI微服务**: 专注于推荐算法核心计算，无状态设计

### 2. 原MongoDB版本 vs FastAPI版本对比

| 功能 | MongoDB版本 | FastAPI微服务版本 |
|------|-------------|------------------|
| 数据存储 | Python直接操作MongoDB | SpringBoot管理，Python无状态 |
| 算法计算 | ✅ 核心推荐算法 | ✅ 纯算法计算引擎 |
| 用户动量 | MongoDB持久化 | Java传入，Python计算返回 |
| 扩展性 | 受MongoDB连接限制 | 可水平扩展多实例 |
| 部署复杂度 | 需要MongoDB配置 | 独立部署，无依赖 |

## 🏗️ 新架构优势

### 1. **更好的可扩展性**
```
Java SpringBoot (数据层)  ←→  Python FastAPI (算法层)
     │                           │
     ├── MySQL/PostgreSQL        ├── 纯算法计算
     ├── Redis缓存               ├── 无状态设计

```

- **Python**: 擅长机器学习算法、数值计算、科学计算库

## 🔄 工作流程示例

### Java SpringBoot端调用流程：

```java
// 💡 完整的动量管理和推荐流程

// === 1. 用户首次访问或长期动量更新 ===
public void updateUserLongTermMomentum(Long userId) {
    // Java从数据库获取用户历史行为数据
    UserBehaviorData behaviorData = userRepository.findUserBehaviorData(userId);
    
    // 调用Python计算长期动量
    LongTermMomentumRequest request = new LongTermMomentumRequest(userId, behaviorData);
    LongTermMomentumResponse response = pythonApiClient.calculateLongTermMomentum(request);
    
    // Java保存长期动量到数据库
    userMomentumRepository.saveLongTermMomentum(userId, response.getLongTermMomentum());
    userMomentumCache.put(userId + "_long_term", response.getLongTermMomentum());
}

// === 2. 用户点击商品更新推送动量 ===
public void handleUserClick(Long userId, Product clickedProduct) {
    // Java从缓存/数据库获取当前推送动量
    UserMomentum currentPushMomentum = userMomentumCache.get(userId + "_push_momentum");
    if (currentPushMomentum == null) {
        currentPushMomentum = userMomentumRepository.findPushMomentum(userId);
    }
    
    // 调用Python计算新的推送动量
    PushMomentumRequest request = PushMomentumRequest.builder()
        .userId(userId)
        .clickedProduct(clickedProduct)
        .currentMomentum(currentPushMomentum)
        .clickStrength(0.5)
        .build();
    
    PushMomentumResponse response = pythonApiClient.calculatePushMomentum(request);
    
    // Java保存新的推送动量
    UserMomentum newPushMomentum = response.getUpdatedMomentum();
    userMomentumRepository.savePushMomentum(userId, newPushMomentum);
    userMomentumCache.put(userId + "_push_momentum", newPushMomentum);
    
    // 记录点击日志
    clickLogService.saveClickLog(userId, clickedProduct, newPushMomentum);
}

// === 3. 生成推荐 ===
public List<Product> generateRecommendations(Long userId, List<Product> candidateProducts) {
    // Java获取用户最新的推送动量（优先）或长期动量
    UserMomentum userMomentum = userMomentumCache.get(userId + "_push_momentum");
    if (userMomentum == null) {
        userMomentum = userMomentumCache.get(userId + "_long_term");
    }
    if (userMomentum == null) {
        // 如果都没有，调用Python获取默认动量
        DefaultMomentumResponse defaultResponse = pythonApiClient.getDefaultMomentum();
        userMomentum = defaultResponse.getDefaultMomentum();
    }
    
    // 调用Python生成推荐
    RecommendationRequest request = RecommendationRequest.builder()
        .userId(userId)
        .products(candidateProducts)
        .userMomentum(userMomentum)
        .topK(10)
        .includeScores(false)
        .build();
    
    RecommendationResponse response = pythonApiClient.recommendProducts(request);
    
    // Java处理推荐结果
    List<Product> recommendations = response.getRecommendations();
    
    // 保存推荐日志
    recommendationLogService.saveRecommendationLog(userId, recommendations, userMomentum);
    
    // 更新推荐缓存
    recommendationCache.put(userId, recommendations);
    
    return recommendations;
}

// === 4. 完整的三动量推荐（一次性处理点击+推荐） ===
public List<Product> handleClickAndRecommend(Long userId, Product clickedProduct, List<Product> candidates) {
    // 获取长期动量和当前推送动量
    UserMomentum longTermMomentum = userMomentumCache.get(userId + "_long_term");
    UserMomentum currentPushMomentum = userMomentumCache.get(userId + "_push_momentum");
    
    // 调用Python的三动量推荐接口（一次性处理）
    ThreeMomentumRequest request = ThreeMomentumRequest.builder()
        .userId(userId)
        .products(candidates)
        .longTermMomentum(longTermMomentum)
        .currentPushMomentum(currentPushMomentum)
        .clickedProduct(clickedProduct)
        .topK(10)
        .build();
    
    ThreeMomentumResponse response = pythonApiClient.threeMomentumRecommendation(request);
    
    // Java保存更新后的推送动量
    UserMomentum updatedMomentum = response.getUpdatedMomentum();
    userMomentumRepository.savePushMomentum(userId, updatedMomentum);
    userMomentumCache.put(userId + "_push_momentum", updatedMomentum);
    
    return response.getRecommendations();
}
```

### 💾 Java端动量数据管理：

```java
// 动量数据实体
@Entity
public class UserMomentum {
    private Long userId;
    private String momentumType; // "long_term", "push_momentum"
    private String momentumData; // JSON格式存储Python返回的动量数据
    private LocalDateTime lastUpdated;
    private Integer cumulativeClicks; // 推送动量的累积点击数
}

// 动量数据仓库
@Repository
public interface UserMomentumRepository extends JpaRepository<UserMomentum, Long> {
    UserMomentum findByUserIdAndMomentumType(Long userId, String momentumType);
    
    @Query("UPDATE UserMomentum SET momentumData = ?2, lastUpdated = ?3 WHERE userId = ?1 AND momentumType = 'push_momentum'")
    void updatePushMomentum(Long userId, String momentumData, LocalDateTime timestamp);
    
    // 定期清理过期的推送动量
    @Query("DELETE FROM UserMomentum WHERE momentumType = 'push_momentum' AND lastUpdated < ?1")
    void cleanExpiredPushMomentum(LocalDateTime cutoffTime);
}
```

### 职责分离对比：

| 操作类型 | Java SpringBoot | Python FastAPI |
|----------|----------------|----------------|
| 🗄️ 数据库读取 | ✅ userRepository.find() | ❌ 无数据库操作 |
| 💾 数据库写入 | ✅ repository.save() | ❌ 无数据库操作 |
| 🧮 算法计算 | ❌ 不涉及复杂算法 | ✅ 纯算法引擎 |
| 📊 动量计算 | ❌ 只传递数据 | ✅ 三动量核心算法 |
| 🔄 业务逻辑 | ✅ 缓存、日志、通知 | ❌ 无业务逻辑 |
| 💾 长期动量存储 | ✅ 保存到MySQL/Redis | ❌ 只计算不存储 |
| 💾 推送动量存储 | ✅ 保存到MySQL/Redis | ❌ 只计算不存储 |
| 📈 推荐日志 | ✅ 记录所有推荐行为 | ❌ 无日志功能 |
| ⚡ 动量缓存管理 | ✅ Redis缓存策略 | ❌ 无缓存依赖 |

### 🔄 动量数据流转：

```
用户行为数据 (Java DB) 
    ↓
🔥 计算长期动量 (Python API)
    ↓
长期动量数据 (Java DB + Cache)
    ↓
用户点击事件 (Java)
    ↓
🔥 计算推送动量 (Python API) ← 传入当前推送动量
    ↓
新推送动量 (Java DB + Cache)
    ↓
🔥 生成推荐 (Python API) ← 传入最新动量
    ↓
推荐结果 + 推荐日志 (Java DB)
```

## 🎯 java_python_mapper.py 功能解析

这个文件是Java和Python之间的**数据格式兼容层**：

### 主要功能：
1. **数据格式标准化**: 处理Java和Python字段名差异
2. **类型转换**: 确保数据类型在两种语言间正确传递
3. **响应格式化**: 统一API响应格式
4. **错误处理**: 提供友好的错误信息

### 示例转换：
```python
# Java格式 -> Python格式
{
  "productId": "P001",           # -> "product_id": "P001"
  "categoryName": "electronics", # -> "category": "electronics"
  "salePrice": 199.99           # -> "price": 199.99
}
```
